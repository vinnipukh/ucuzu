## Codebase Patterns
- Checks: `uv run pytest` (repo root) and `cd frontend && npm run check`. Both are fast (<10 s).
- Simulate CI (no database) with `PRICES_DB_PATH=/nonexistent/x.db uv run ...`.
- `.gitattributes` normalizes *.md/*.py/*.json/*.yml to LF on commit; Windows Python `open(p, "w")` writes CRLF, so pass `newline="\n"` when scripting edits.
- PyYAML is not a project dependency: validate YAML with `uv run --with pyyaml python -c ...`.
- After editing `frontend/package.json`, run `npm install --package-lock-only` so `npm ci` stays in sync.
