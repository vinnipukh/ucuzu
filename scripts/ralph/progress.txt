## Codebase Patterns
- Checks: `uv run pytest` (repo root) and `cd frontend && npm run check`. Both are fast (<10 s).
- Simulate a no-database setup with `PRICES_DB_PATH=/nonexistent/x.db uv run ...`.
- `.gitattributes` normalizes *.md/*.py/*.json/*.yml to LF on commit; Windows Python `open(p, "w")` writes CRLF, so pass `newline="\n"` when scripting edits.
- Git Bash heredocs can fail on long or quote-heavy content; write large content with the Write tool.
- GitHub heading anchors: lowercase, spaces -> `-`, and `:`, backticks, `/`, `.` are dropped (e.g. "Large files: `scripts/data_files.py`" -> `#large-files-scriptsdata_filespy`).
- Link check (run from the doc's directory): `grep -o "](\([^)]*\))" FILE | sed 's/](\(.*\))/\1/; s/#.*//' | grep -v '^http' | while read l; do [ -e "$l" ] || echo MISSING $l; done`
